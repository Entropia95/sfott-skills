## Vuoi creare una skill?

Hai un'idea per una nuova competenza di cui nessuno sentiva il bisogno?

Sei nel posto giusto.

1. Crea un fork di questa repository.
2. Crea una cartella all'interno di `skills/`.
3. Aggiungi un file `SKILL.md` seguendo il formato Agent Skills.
4. Inserisci eventuali riferimenti o risorse aggiuntive.
5. Testa la tua skill.
6. Invia una Pull Request.

Prima di contribuire, consulta [CONTRIBUTING.md](CONTRIBUTING.md).

## Qualche regola

- Le skill devono essere originali, interessanti, divertenti ma sopratutto completamente inutili.
- Niente istruzioni malevole, comportamenti dannosi o funzionalità ingannevoli.
- Niente per cui si rischi l'arresto.
- Rispetta copyright, marchi e diritti della personalità.
- Divertiti.

L'ironia è benvenuta. Le cause legali un po' meno.
